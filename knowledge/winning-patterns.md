# 売れる有料記事の型

note で有料記事が売れる要因をまとめたものです。各エージェントは、ここを出発点にしつつ、実行時の調査で裏を取ってください（ここにあるのは仮説で、確定した事実ではありません）。

## 1. 売れやすいジャンルの傾向（仮説）
| ジャンル | 売れる理由 | 注意点 |
|---|---|---|
| AI 活用（ChatGPT / Claude のプロンプト集、業務効率化） | 変化が速く、まとまった情報が少ない | 情報がすぐ古くなる。更新日を書く |
| 副業・スキル販売（ライティング、デザイン、動画編集） | 収入に直結する | 「稼げる」の断定は禁止 |
| 転職・キャリア・資格 | 人生の大きな決断で、お金を払う理由がある | 個人差を明記する |
| 生活の節約・お金の制度（税金、補助金、ふるさと納税、新 NISA の仕組み） | 得する金額がはっきりしている | 投資助言にならないようにする |
| 人間関係・恋愛・コミュニケーション | 悩みが深く、人に相談しにくい | 体験の作り話はしない |
| 健康・ダイエット・睡眠 | 需要が大きい | 薬機法。効果の断定は禁止 |
| 趣味・ハウツー（ガジェット、DIY、ゲーム攻略） | 具体的な手順に価値がある | 市場は小さめ。ニッチを狙う |

## 2. 価格帯の目安
| 価格 | 向いている記事 |
|---|---|
| 100〜300 円 | 短い記事、お試し、シリーズの入り口 |
| 480〜980 円 | 1 つの悩みを解決するハウツー。初めての有料記事はここ |
| 1,480〜2,980 円 | テンプレ・チェックリスト付きの網羅ガイド |
| 3,980 円以上 | 実績と信頼がある人の体系的な教材。最初は避ける |

## 3. タイトルの型
- 数字: 「○ステップ」「○選」「○日で」
- ベネフィット: 読むと何が手に入るか
- 対象: 「○○な人向け」と読者を絞る
- 意外性: 「○○はやめなさい」「実は○○だった」
- 例: 「【テンプレ付き】初心者が 30 日で○○できるようになった 7 ステップ」

## 4. 構成の型
1. 冒頭 3 行で悩みを言い当て、得られるものを言い切る
2. 信頼の根拠
3. 無料で役立つ答えの一部（ここをケチらない）
4. 有料部分の目次と特典の紹介
5. 橋渡し文 → **有料ライン**（全体の 30〜40% の位置）
6. 再現できる手順、テンプレ、失敗例と対処法
7. 「今日やること」で締める

## 5. 売上を伸ばす工夫
- 無料部分だけで「スキ」をもらえる質にする（スキが多いとおすすめに載りやすい）
- 同じテーマで無料記事を何本か書き、有料記事へリンクする
- シリーズ化して、まとめを有料マガジンにする
- 購入者の感想を（許可を得て）追記する
