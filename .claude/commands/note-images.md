ChatGPT で作った画像を記事に埋め込んでください。

対象: $ARGUMENTS（空なら `articles/` の中で最も新しい記事フォルダ）

## 手順

1. 記事の `images/` フォルダの中身と、`article.md` の `<!-- FIGURE: ... -->` を確認する。

2. **ファイル名を合わせる**
   ChatGPT からダウンロードした画像は「ChatGPT Image ….png」のような名前になっていることが多い。
   `fig<番号>-…` の名前になっていない画像は、Read で開いて内容を見て、どの FIGURE の図かを判断し、
   `fig<番号>-<英字>.<元の拡張子>` に `mv` で名前を変える。どれか判断できない画像はユーザーに確認する。

3. `python3 scripts/generate_figures.py <article.md>` を実行して記事に埋め込む。

4. **確認する**
   埋め込んだ各画像を Read で開き、指示した文字が正しく書かれているか・内容が合っているかを確認する。
   問題がある図は、ChatGPT にそのまま頼める修正依頼文（例:「『入力』の文字が崩れているので正確に書き直してください」）をユーザーに渡す。

5. **報告する**
   埋め込んだ図、まだ画像がない図、要修正の図をまとめる。全部そろったら、note には本文を貼り付けて画像を手動でアップロードすることを伝える。
   `.webp` の画像は note にアップロードできない場合があるので、その場合は PNG で保存し直すよう案内する。
