note 有料記事を作ります。テーマのヒント: $ARGUMENTS（空ならゼロから探す）

以下の順にサブエージェントを呼び出してください。各工程の成果物は同じフォルダに保存します。

## 0. 準備
- 今日の日付と仮の slug（英小文字とハイフン）で `articles/<YYYY-MM-DD>-<slug>/` を作る。テーマ決定後に slug を付け直してよい。

## 1. テーマ発掘 → **ユーザー確認**
- `note-market-scout` に、ヒントと出力先フォルダを渡す。
- 上位 3 案を表で示し、**どれで書くかユーザーに選んでもらう**（ヒントでテーマが明確に決まっている場合も、確認だけはする）。

## 2. 取材
- `note-researcher` に、選ばれたテーマ・想定読者・出力先フォルダを渡す。

## 3. 企画 → **ユーザー確認**
- `note-planner` に出力先フォルダを渡す。
- タイトル案上位 3 本、価格、目次、有料ラインの位置を示し、**この企画で書いてよいか確認する**。修正希望があれば planner に再依頼する。

## 4. 執筆と校閲（最大 3 周）
- `note-writer` に出力先フォルダを渡して本文を書かせる。
- `note-editor` に採点させる。
- 差し戻しなら、`04_review.md` の指示を添えて `note-writer` に書き直させ、再度 `note-editor` に回す。3 周しても合格しなければ、残った課題をそのままユーザーに伝える。

## 5. 仕上げ
- ユーザーに次をまとめて伝える。
  - 記事ファイルの場所（`03_article.md`）、タイトル、価格、文字数、点数
  - note への貼り付け手順: 本文を貼る → `<!-- ここに有料ライン -->` の位置で有料エリアを設定 → 価格・ハッシュタグ・サムネを設定
  - 編集長の「さらに売るための改善案」
- 投稿は必ずユーザー本人が行う（自動投稿はしない）。
