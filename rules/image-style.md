# 画像スタイルガイド（ChatGPT 画像生成用）

記事のサムネイル（見出し画像）と解説図を、ChatGPT で日本語プロンプトから生成するためのルール。
`note-image-prompter` エージェントはこのファイルを必ず読んでからプロンプトを書く。
画風を変えたいときは、このファイルの「共通スタイル」を書き換える。

---

## 共通スタイル（全プロンプトの末尾にそのまま入れる）

```
【画風】パステルカラーを基調とした、やわらかいアニメ調のイラスト。
淡いピンク、ミントグリーン、ラベンダー、スカイブルー、クリーム色を中心に、彩度は低め、明るく清潔感のある雰囲気。
輪郭線は細くやわらかく、陰影はセル画風のやさしい2段階。背景はシンプルで、白〜クリーム色の余白を多めにとる。
写真風・リアル調・3DCG風・濃い原色・暗い色調・ホラー表現は使わない。
```

## 登場キャラクター（任意・シリーズ感を出すとき）

```
【キャラクター】30代くらいの穏やかな日本人の会社員（性別は限定しない、やわらかい表情、ショートヘア、ベージュのカーディガン）。
デフォルメは控えめな等身（5〜6頭身）。
```

キャラクターを毎回そろえたいときは、ChatGPT の同じチャットで続けて生成するか、最初に作った画像を添付して「この人物と同じキャラクターで」と書き添える。

---

## サムネイル（見出し画像）

- ファイル名：`images/thumbnail.png`（`.jpg` も可）
- note の推奨サイズは **1280×670px（約1.91:1）**。ChatGPT では「横長（3:2）」で生成し、note のトリミング画面で上下が少し切られる前提にする。
- **重要なもの（人物の顔・タイトル文字）は画面の中央 70% に収め、上下に余白をとる**よう指示する。
- 画像内の文字は **タイトルを短くした1行（10〜15文字以内）だけ**。長い文字は崩れやすい。
- 入れる文字は「」で囲んで一字一句指定し、「文字は正確にこの通りに、丸みのある太めの日本語ゴシック体で」と書く。
- 構図は「記事のテーマを象徴するモチーフ＋キャラクター」。格言シリーズは格言の情景を比喩的に描く。

## 解説図

- ファイル名：`images/fig1.png`, `images/fig2.png` …（記事中の `![図N：…](images/figN.png)` と一致させる）
- サイズ：基本は「横長（3:2）」。手順や縦の流れを見せる図だけ「正方形」も可。
- 1枚で伝えることは **1つだけ**（比較・流れ・関係・before/after のどれか）。
- 図中ラベルは **最大5個、各8文字以内**。すべて「」で一字一句指定する。
- 矢印・吹き出し・アイコンなど、図の要素と配置（左／中央／右、上→下）を具体的に書く。
- 統計値やグラフの数値など、記事本文にない数字を図に入れない（捏造防止）。

---

## プロンプトの型

```
note記事の〈サムネイル／解説図〉を作ってください。

【サイズ】横長（3:2）
【テーマ】〈記事・図のテーマを1〜2文で〉
【構図】〈何をどこに配置するか。左右・上下・中央を具体的に〉
【入れる文字】「〈一字一句〉」（丸みのある太めの日本語ゴシック体。文字は正確にこの通りに）
【雰囲気】〈やさしい／前向き／落ち着いた など〉
〈共通スタイル〉
```

文字が崩れたときの再指示例（image-prompts.md の末尾に必ず添える）：

```
画像はこのままで、文字だけを「〈正しい文字〉」に正確に直してください。
```
